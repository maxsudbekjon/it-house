# Статистика (`statistics`)

Цифры для блока статистики на сайте: студенты, выпускники, трудоустройство, направления. Значения вводит администратор, кроме `total_directions`: оно считается автоматически.

## Эндпоинты

| Метод | URL | Доступ | Описание |
|---|---|---|---|
| `GET` | `/api/statistics/` | все | Список записей. На сайте используется одна запись |
| `GET` | `/api/statistics/{id}/` | все | Одна запись |
| `POST` | `/api/statistics/` | superuser | Создать |
| `PATCH` | `/api/statistics/{id}/` | superuser | Изменить часть полей |
| `DELETE` | `/api/statistics/{id}/` | superuser | Удалить |

- `GET /api/statistics/` возвращает **массив**, даже если запись одна.
- Запись без токена возвращает `401`, с токеном не-superuser — `403`. `PUT` не поддерживается (`405`).

## Формат ответа

```json
{
  "id": 1,
  "total_directions": 6,
  "total_students": 3000,
  "total_graduates": 2200,
  "total_employed": 1000,
  "employment_rate": 40,
  "avg_duration": 7.0,
  "avg_start_salary": 300.0,
  "partners": 3,
  "created_at": "2026-01-05T09:31:37.161723+05:00",
  "updated_at": "2026-01-06T10:57:26.505367+05:00"
}
```

| Поле | Тип | Запись | Описание |
|---|---|---|---|
| `total_students` | int ≥ 0 | да | Всего студентов |
| `total_graduates` | int ≥ 0 | да | Всего выпускников |
| `total_employed` | int ≥ 0 | да | Всего трудоустроенных выпускников |
| `employment_rate` | int 0–100 | да, по умолчанию `0` | % выпускников, трудоустроенных в течение 3 месяцев после выпуска |
| `total_directions` | int ≥ 0 | нет, вычисляется | Количество направлений = количество курсов |
| `avg_duration` | float | да | Средняя длительность курса, в месяцах |
| `avg_start_salary` | float | да | Средняя стартовая зарплата выпускника |
| `partners` | int ≥ 0 | да | Количество партнёров |

`id`, `created_at`, `updated_at` и `total_directions` доступны только для чтения.

### `employment_rate`

- Только целое число от 0 до 100. Значения `97.5`, `-1`, `101` дают `400`:

```json
{"employment_rate": ["Ensure this value is less than or equal to 100."]}
```

- Ограничение проверяется в трёх местах: валидатор модели (админка и API), `CHECK` в Postgres (`statistics_employment_rate_lte_100`) и тип `smallint` с `CHECK >= 0`.
- При добавлении поля существующая запись получила `0`. Пока администратор не введёт реальное значение, сайт показывает 0%.
- **Согласованность с другими цифрами.** Для одной и той же группы выпускников 3-месячный процент не может быть больше общего процента трудоустроенных `total_employed / total_graduates`. Иначе на сайте будут противоречивые цифры. Жёстко это не проверяется, потому что бизнес может считать по другой группе (например, только по последнему выпуску). Подсказка для администратора есть в админке, см. ниже.

### `total_directions`

- Считается как `Course.objects.count()`: столько же элементов, сколько возвращает `/api/courses/`.
- Меняется, когда в админке добавляют или удаляют курс. Передать его в `POST` / `PATCH` нельзя: поле молча игнорируется.

## Админка

`/admin-page-locked/mainapp/statistics/`

- `employment_rate` редактируется в форме. Под полем есть подсказка с определением метрики.
- Колонка и поле **Overall employment rate, %** показывают расчётный `total_employed / total_graduates` в процентах, округлённый. Если `total_graduates = 0`, выводится `-`. Значение считается по **сохранённым** данным и обновляется после сохранения. Если `employment_rate` больше этой цифры, проверьте данные.
